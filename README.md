# Cierres Guyana

App de Android para registrar las operaciones de los gestores, sacar el cierre en GYD y calcular la ganancia.

## Cómo conseguir el APK
Cada vez que se sube un cambio a `main`, GitHub compila el APK solo (pestaña **Actions**).
Cuando termina, el APK aparece en **Releases** → `CierresGuyana.apk`. Ábrelo desde el móvil para instalarlo
(Android pedirá permitir la instalación desde esa fuente).

Los datos se guardan en el móvil. Usa **Copia de seguridad** dentro de la app para no perderlos.
